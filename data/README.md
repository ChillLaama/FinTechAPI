# Training Data

This directory holds the Kaggle CSV used by the ML Trainer.

## Download

1. Go to <https://www.kaggle.com/datasets/chitwanmanchanda/fraudulent-transactions-data>
2. Download **Fraud.csv** (~494 MB, 6 362 620 rows × 11 columns).
3. Place it in this folder so the path is `data/Fraud.csv`.

The CSV is excluded from version control via `.gitignore`.
